# 워크숍 지원전략
- ## 프로젝트 1~2개를 아주 잘 설명하기. “무슨 모델 썼어요”보다 문제가 뭐였는지 → 내가 뭘 맡았는지 → 막힌 점을 어떻게 해결했는지 → 결과가 어땠는지가 중요해.
- ## 관심 분야를 2개 정도로 좁히기. 아직 확정 안 해도 됨. 예: 추천시스템 / NLP, 또는 CV / causal ML처럼 “현재는 이 두 분야가 궁금하다” 정도.

- ## 연구하고 싶은 이유를 한 문장으로 만들기. “대학원 갈지 고민돼서요”보다 “수업과 프로젝트는 해봤는데, 실제 연구에서 문제를 정의하고 실험을 반복하는 과정이 저에게 맞는지 확인하고 싶다”가 훨씬 좋음.

- ## 교수님께 물어볼 질문을 준비하기. “인턴 뽑으세요?”만 묻는 것보다 “학부 인턴이 들어오면 처음 어떤 업무부터 맡게 되는지”, “어떤 역량이 있어야 연구에 실제로 기여할 수 있는지”, “학부 프로젝트와 연구실 연구에서 가장 큰 차이가 뭔지” 같은 질문이 좋음.
